# Project Demonstration

Project: Implement Client Script & UI Policy (Incident)

## Demonstration Objective

The demonstration presents the completed ServiceNow Incident configuration and shows how the configured rules affect Incident records.

## Demonstration Sequence

1. Introduce the project and its objective.
2. Open the Incident module.
3. Show the High Impact Control UI Policy.
4. Explain the configured UI Policy Actions.
5. Demonstrate automatic Urgency assignment.
6. Demonstrate Assigned To validation during submission.
7. Demonstrate State restriction through list editing.
8. Demonstrate State modification through the Incident form.
9. Present the final working result.
